## 📖 Overview

Welcome to the **GitHubIntras** repository! This project contains comprehensive data exploration, preprocessing, and machine learning models tailored for the KDAG Intras problem statement. 

## 🚀 Features

- **Exploratory Data Analysis (EDA):** Deep dive into dataset distributions, missing values, and feature correlations.
- **Data Preprocessing:** Robust handling of categorical data, scaling numerical features, and handling outliers.
- **Predictive Modeling:** Utilizing CatBoost and other state-of-the-art machine learning techniques to achieve high accuracy.

## 📂 Repository Structure

- `EDA.ipynb` - Comprehensive Exploratory Data Analysis.
- `PreProcessing.ipynb` - Data cleaning and feature engineering pipelines.
- `PS/` - Problem statement and dataset files.
- `*.pdf` - Correlation matrices and pre-model reports.

## 🛠️ Setup & Installation

Clone this repository and explore the notebooks:

```bash
git clone https://github.com/ASMITSARKAR/GitHubIntras.git
cd GitHubIntras
jupyter notebook
```
